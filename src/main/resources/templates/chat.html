문서를 업로드하고, 업로드한 문서를 기반으로 질문할 수 있습니다.

문서 업로드

PDF, TXT, DOC, DOCX, PPT, PPTX 파일을 업로드할 수 있습니다.

현재 브라우저 업로드 기록

아직 업로드한 문서가 없습니다.

사용 방법

  1. 먼저 회사 문서 파일을 업로드합니다.
  2. 업로드 성공 메시지를 확인합니다.
  3. 아래 질문 입력창에서 문서 내용에 관해 질문합니다.
  4. AI 답변 아래 참고 문서 이름을 확인합니다.

대화 내역

현재 로그인 사용자의 질문과 AI 답변입니다.

문서를 업로드한 다음 질문을 입력해 주세요.
